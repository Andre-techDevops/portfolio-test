# Portfolio Test

Repositório de teste para validar o funcionamento do GitHub Pages.

## Sobre

Este repositório é um teste mínimo para verificar se o GitHub Pages está funcionando corretamente.

## Arquivos inclusos

- `index.html` - Página principal
- `styles.css` - Estilos CSS
- `script.js` - JavaScript
- `.nojekyll` - Configuração do GitHub Pages
- `README.md` - Este arquivo

## Como acessar

O site está disponível em:

```
https://Andre-techDevops.github.io/portfolio-test/
```

## Próximos passos

1. Configurar GitHub Pages em Settings → Pages
2. Escolher GitHub Actions como source
3. Aguardar 2-5 minutos para o site publicar
4. Acessar a URL acima
